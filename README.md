# AAT 4 — AI-Assisted Workflow Chatbot

A simple, AI-powered chatbot built as part of the **AAT 4 Assignment** on designing an AI-assisted workflow using prompt engineering.

## 🔗 Live Demo
👉 [Open Chatbot](https://tharun019.github.io/simple_chatbot/)

## 📌 About
This chatbot is **restricted to the AAT 4 domain** — it answers questions related to:
- The AI-assisted workflow for summarizing technical documents
- Prompt engineering concepts used in the assignment
- The 3 prompt templates designed and tested
- Evaluation results and key findings

## 🛠️ Tech Stack
- HTML, CSS, JavaScript (single file, no dependencies)
- Google Gemini AI API (`gemini-2.0-flash`)
- Hosted via GitHub Pages

## 📚 Assignment Context
**Problem:** Undergraduate engineering students struggle to summarize long technical documents.  
**Solution:** A 4-step AI-assisted workflow using prompt engineering to identify key topics, generate structured summaries, and simplify jargon.
